# 가구공사 마진계산기

가구공사 현장의 비용을 입력하면 비용 총합계, 공사 순마진, 이익률을 계산하는 웹 페이지입니다.
구글 스프레드시트를 공용 저장소로 연결하면 모든 직원이 같은 현장 목록과 PB 단가를 함께 씁니다.

접속 주소: https://mangudai0-byte.github.io/furniture-margin-calculator/

## 기능

- **계산**: 날짜, 업체, 현장명, 총공사금액과 비용 6개 항목 입력
  - PB: 15T / 18T / 우라 소요량(장) × 장당 단가로 자동 계산 (기본 70,000 / 80,000 / 39,000원, 수정 가능)
  - 기본기물(경첩·다릿발·걸레받이 등): PB 금액 × 5% (비율 수정 가능)
  - MD, 선택기물, 대리석, 시공비: 금액 직접 입력
- **현장 목록**: 업체·연도·현장명으로 거르고 합계 확인, 눌러서 다시 수정, 저장한 사람 표시
- **업체별 분석**: 업체별 현장 수, 공사금액, 비용, 순마진, 이익률, 현장당 평균 마진
- **공용 저장소**: 구글 스프레드시트에 현장과 단가를 모아 저장, 직원용 연결 링크
- **백업**: 현장 목록을 .json 파일로 내보내고 불러오기

## 공용 저장소 설정 (관리자가 한 번만)

### 1. 스프레드시트와 스크립트 만들기

1. [sheets.new](https://sheets.new)에서 새 스프레드시트를 만들고 이름을 `가구공사 마진 현장목록`처럼 정합니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있는 내용을 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs)의 내용을 통째로 붙여 넣습니다.
4. 맨 위 `TEAM_CODE = '여기에-팀-코드를-적으세요'`의 따옴표 안을 직원들과 공유할 팀 코드로 바꿉니다. 남이 짐작하기 어려운 값으로 정하세요.
5. 저장(디스크 아이콘)을 누릅니다.

### 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴에서 유형을 **웹 앱**으로 고릅니다.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 설정하고 **배포**를 누릅니다.
4. 권한 승인 창이 나오면 본인 구글 계정을 고르고 허용합니다. "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다. 본인이 만든 스크립트라서 나오는 경고입니다.
5. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

### 3. 직원에게 주소 보내기

웹 앱 주소는 `index.html`의 `DEFAULT_URL`에 들어 있습니다. 직원에게는 접속 주소와 팀 코드를 알려 주면 됩니다.
직원이 처음 열면 계산 화면 위에 **공용 저장소에 연결하기** 칸이 나오고, 팀 코드와 이름을 넣으면 바로 연결됩니다.
팀 코드까지 들어간 링크를 보내고 싶으면 **공용 저장소** 탭의 **직원에게 보낼 연결 링크**를 복사해서 보내세요.

스크립트를 새로 만들어 웹 앱 주소가 바뀌었다면 `index.html`의 `DEFAULT_URL`도 바꿔야 합니다.

스프레드시트에는 `현장` 시트(현장별 한 줄)와 `설정` 시트(PB 단가, 기본기물 비율)가 자동으로 만들어집니다. 시트에서 직접 단가를 고쳐도 계산기에 반영됩니다.

### 참고

- 스크립트 내용을 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 웹 앱 URL은 그대로 유지됩니다.
- 팀 코드를 바꾸려면 `TEAM_CODE`를 고치고 위처럼 새 버전으로 배포한 뒤, 계산기에서 다시 연결하고 새 링크를 보내세요. 예전 링크는 더 이상 작동하지 않습니다.
- 팀 코드를 아는 사람은 현장을 보고, 고치고, 지울 수 있습니다. 퇴사자가 생기면 팀 코드를 바꾸세요.
- 스프레드시트의 **파일 → 버전 기록**으로 실수로 지운 내용을 되살릴 수 있습니다.

## 공용 저장소 없이 쓰기

연결하지 않으면 현장과 단가는 그 브라우저에만 저장됩니다. 현장 목록 탭의 **백업 파일 내보내기 / 불러오기**로 다른 기기에 옮길 수 있습니다.
