# 가구공사 마진계산기

가구공사 현장의 비용을 입력하면 비용 총합계, 공사 순마진, 이익률을 계산하는 웹 페이지입니다.

## 기능

- **계산**: 날짜, 업체, 현장명, 총공사금액과 비용 6개 항목 입력
  - PB: 15T / 18T / 우라 소요량(장) × 장당 단가로 자동 계산 (기본 70,000 / 80,000 / 39,000원, 수정 가능)
  - 기본기물(경첩·다릿발·걸레받이 등): PB 금액 × 5% (비율 수정 가능)
  - MD, 선택기물, 대리석, 시공비: 금액 직접 입력
- **현장 목록**: 저장한 현장을 업체·연도·현장명으로 거르고 합계 확인, 눌러서 다시 수정
- **업체별 분석**: 업체별 현장 수, 공사금액, 비용, 순마진, 이익률, 현장당 평균 마진

## 사용법

`index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속합니다. 별도 설치가 필요 없습니다.

저장한 현장과 단가는 그 브라우저(localStorage)에만 보관됩니다. 다른 기기나 다른 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 함께 지워집니다.
